# Writing Module — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Tasks 10–13 are content tasks.

**Goal:**
- Graded writing: a letter task type with AI rubric grading consistent through anchor letters, and marked-up feedback with criterion cards.
- The cross-module error log, with a top-mistakes card.
- Typing helpers (umlaut keys, word counter, spellcheck off in timed Teile).
- Writing content for all 15 formats.

**Architecture:**
- **Pure:** `lib/writing/` (rubrics, the grading prompt, the reply parser with offset recovery, scoring) and `lib/errors/` (taxonomy, snippets, aggregation).
- **Services:** grading is one service (`letterGradingService`), used by lessons, the Teil runner and Freestyle free writing. `errorLogService` is written to from every grader.
- **Typing helpers:** components that replace every German input.

**Tech Stack:** Next.js 16, React 19, Tailwind 4 and shadcn/ui, better-sqlite3, next-intl 4, vitest 5.

**Spec:** `docs/superpowers/specs/2026-09-29-writing-design.md`

**Precondition:** everything up to and including Listening is merged.

## Global Constraints

- **Rubric points:** grades A–E, per criterion and per format. The lesson rubric is 3 criteria at A 5 / B 3 / C 1 / D 0.
- **Lesson grade:** ≥ 60% of the rubric points is correct, ≥ 40% is almost, and anything else is wrong.
- **Marks:** `original` substrings are located in the text in order. A mark that can't be found is dropped, and an unknown category becomes `other`. Missing criteria make the reply `ai_bad_reply`.
- **Anchors:** 2–3 per grading call (A, D, and B when present). A missing anchor file grades with the rubric only and raises a `content_issues` info notification.
- **Letter tasks:** not test-out eligible, and never in the Daily Queue.
- **Revising:** each submission in a lesson or Freestyle is a new attempt, with versions shown. A Teil letter attempt is final once graded; a grading failure keeps it open for a resubmit.
- **Error log:**
  - sources are `lesson`, `teil`, `freestyle_chat` and `freestyle_writing` (and `speaking` later);
  - snippets are at most 80 characters, cut at word boundaries;
  - the top 5 categories come from the last 30 days.
- **Typing helpers:** every German text input uses `GermanTextInput` or `GermanTextarea`. The umlaut row toggle is remembered in `localStorage` (with try/catch). Spellcheck is off only in the timed Teil runner and mocks.
- **Existing rules:** `res.ok` and `role="alert"`; `delayedResponse`; student text in en and de; admin in English.

## Review Focus

1. **Repeated wrong text:** a letter that contains the marked wrong text twice gets the mark on the first occurrence after the previous mark, not always the first in the text (Task 4).
2. **Umlaut at a selection:** clicking "ä" with text selected replaces the selection, and the caret lands after the inserted letter (Task 2).
3. **Slow grading:** the Teil submit button stays disabled while grading runs for 40 s, and a second click never creates a second grading call (Task 7).
4. **Empty letter:** submitting whitespace is refused with `bad_request` before any AI call (Task 6).
5. **An error log fed from nowhere:** the Dashboard card is hidden when there are no entries in the last 30 days, not shown empty (Task 9).

```tsx
'use client';

import { useTranslations } from 'next-intl';

const LETTERS = ['ä', 'ö', 'ü', 'ß', 'Ä', 'Ö', 'Ü'];

// Inserts at the caret of `target`, replacing any selection, and keeps focus there.
export function insertAtCaret(el: HTMLInputElement | HTMLTextAreaElement, text: string): void {
  const start = el.selectionStart ?? el.value.length;
  const end = el.selectionEnd ?? start;
  const next = el.value.slice(0, start) + text + el.value.slice(end);
  const setter = Object.getOwnPropertyDescriptor(Object.getPrototypeOf(el), 'value')!.set!;
  setter.call(el, next);
  el.dispatchEvent(new Event('input', { bubbles: true }));
  el.focus();
  el.setSelectionRange(start + text.length, start + text.length);
}

export function UmlautRow({ target }: { target: () => HTMLInputElement | HTMLTextAreaElement | null }) {
  const t = useTranslations('typing');
  return (
    <div className="flex gap-1" role="group" aria-label={t('umlauts')}>
      {LETTERS.map((letter) => (
        <button
          key={letter}
          type="button"
          aria-label={t('insert', { letter })}
          className="rounded-md border border-border px-2 py-1 text-sm hover:bg-surface-raised"
          // keep focus in the field: act on mousedown, prevent the blur
          onMouseDown={(e) => e.preventDefault()}
          onClick={() => {
            const el = target();
            if (el) insertAtCaret(el, letter);
          }}
        >
          {letter}
        </button>
      ))}
    </div>
  );
}
```
